@AGENTS.md

**IMPORTANT: Always read AGENTS.md first before working on this project.**

AGENTS.md contains critical instructions about:
- Reading `buildLog.md` before making any changes
- Mandatory updates to `buildLog.md` for architecture, data, design, and behaviour changes
- Project conventions and context

Then, depending on the task:
- **Any UI work** (screens, components, styles, copy, animation): read `DESIGN.md`, and let the `african-spaces-design` skill guide the build. To audit UI, use the `african-spaces-design-review` skill.
- **Any database work** (SQL, RLS, RPCs, storage, Edge Functions): read `DATABASE.md`.

Do not start work without reading AGENTS.md and buildLog.md.
